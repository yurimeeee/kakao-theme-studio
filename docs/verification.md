## 수동 확인 (이번 세션에서 실행)

- Playwright 스크린샷으로 1280 / 768 / 390 / 320px 에디터, 바텀시트, 4개 미리보기 화면, 내 작업, 저장 다이얼로그를 눈으로 확인하고 디자인 시안(웹·모바일 HTML)과 비교. 320px에서 미리보기 탭이 잘리는 문제, 데스크톱에서 긴 속성 패널 때문에 미리보기 영역이 늘어나는 문제, 미리보기 배율 계산이 자기 높이를 참조하던 문제를 발견해 수정
- 내보낸 `.ktheme`를 풀어 생성 PNG(말풍선·선택 상태·기본 프로필·암호 표시·테마 아이콘)를 확인

## 알려진 제한

- **형식 근거가 참고 파일 1개뿐**: 최신 앱이 지원하는 속성 범위, 빈 `theme-url` 허용, 같은 theme-id 재설치 동작, 생성 암호 표시 크기(48pt)는 추정입니다.
- **탭**: 친구·채팅·지금(오픈채팅)·쇼핑·더보기 편집 가능. 지금·쇼핑 키는 두 번째 참고 테마의 CSS 주석이 근거이며, 실제 앱 적용은 기기 검증 대기입니다.
- **말풍선**: 꼬리 없는 직각·둥근·캡슐만 생성. 캡슐 반경 17pt는 한 줄 높이 추정값입니다. 이미지 말풍선은 업로드 이미지를 @3x로 간주합니다. 올릴 때 같은 줄이 반복되는 구간을 찾아 늘림 기준점과 텍스트 여백을 자동으로 정합니다(사진처럼 반복 구간이 없으면 직접 조절).
- **이미지 편집**: 자르기 위치 조절 UI는 없습니다(배경·프로필은 가운데 기준 cover).
- **로컬 보관**: 브라우저 데이터 삭제·시크릿 모드·저장소 축출로 사라질 수 있습니다. 다른 기기와 동기화되지 않습니다(2차 범위).
- **미리보기**: 카카오톡 화면을 근사한 웹 렌더링이며 실제 글꼴·간격과 다를 수 있습니다.
