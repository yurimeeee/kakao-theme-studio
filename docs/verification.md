## 알려진 제한

- **형식 근거가 참고 파일 1개뿐**: 최신 앱이 지원하는 속성 범위, 빈 `theme-url` 허용, 같은 theme-id 재설치 동작, 생성 암호 표시 크기(48pt)는 추정입니다.
- **탭**: 친구·채팅·지금(오픈채팅)·쇼핑·더보기 편집 가능. 지금·쇼핑 키는 두 번째 참고 테마의 CSS 주석이 근거이며, 실제 앱 적용은 기기 검증 대기입니다.
- **말풍선**: 꼬리 없는 직각·둥근·캡슐만 생성. 캡슐 반경 17pt는 한 줄 높이 추정값입니다. 이미지 말풍선은 업로드 이미지를 @3x로 간주합니다. 올릴 때 같은 줄이 반복되는 구간을 찾아 늘림 기준점과 텍스트 여백을 자동으로 정합니다(사진처럼 반복 구간이 없으면 직접 조절).
- **이미지 편집**: 자르기 위치 조절 UI는 없습니다(배경·프로필은 가운데 기준 cover).
- **로컬 보관**: 브라우저 데이터 삭제·시크릿 모드·저장소 축출로 사라질 수 있습니다. 다른 기기와 동기화되지 않습니다(2차 범위).
- **미리보기**: 카카오톡 화면을 근사한 웹 렌더링이며 실제 글꼴·간격과 다를 수 있습니다.

### 통합 테스트(`*.cloud.test.ts`)가 다루는 위험

- 저장: 설정은 Firestore, 원본은 소유자 경로에 해시 이름으로 저장되고 Firestore에 이미지 바이트가 없음 / 비활성 원본도 저장 / 두 번째 저장에서 바뀌지 않은 이미지를 다시 올리지 않음(Storage generation 동일) / 같은 기준에서 두 번 저장하면 두 번째가 `conflict`, 먼저 저장한 값 유지 / 이미지 누락으로 실패하면 이전 활성 리비전 그대로 / 다른 계정에 연결된 사본·삭제된 테마 저장 거부 / 비로그인 저장 거부
- 권한: 다른 계정·비로그인은 테마 문서·원본 파일을 읽기·수정·삭제·덮어쓰기 불가, 남의 이름으로 테마 생성 불가
- 정리: 유예 기간 안의 고아 파일 보존, 이후 삭제 / 활성·직전 리비전 파일만 남음 / 오래된 리비전 문서 삭제 / 테마 삭제 시 함수가 파일·리비전 제거
- 공유: 공개 → 비로그인 조회·이미지·썸네일 다운로드, 비활성 원본은 공개 사본에 없음 / 링크 공개는 갤러리 검색에 안 나옴 / 비공개 전환 즉시 문서·파일 접근 차단 후 서버가 사본 삭제 / 링크 변경 시 이전 링크·파일 차단 / 테마 삭제 시 share도 삭제 / 저장하면 공개 사본 갱신
- 위조 방지: 비로그인·타 계정의 share 수정·업로드 불가, 소유자도 `downloadCount` 변경 불가, 남의 테마로 share 생성 불가
- 갤러리: 공개만, 한국어 부분 검색·대소문자·공백 정규화, 페이지 2개에 걸쳐 중복·누락 없음, 인기순 = 서로 다른 계정 다운로드 수(같은 계정 재다운로드·소유자 제외)
- `recordDownload`: 잘못된 ID·없는 share 거부

### E2E(`e2e-cloud/`, 실제 Chromium + 에뮬레이터)

| 시나리오 | 확인 내용 |

| 충돌 | 기기 A 저장 → 기기 B가 열어 저장 → 기기 A 저장 시 "다른 곳에서 먼저 저장됐어요" → 클라우드 버전 불러오기 → B의 이름 표시 |

## 개발 중 발견해 고친 문제

- 새 테마 저장 트랜잭션이 존재하지 않는 문서를 읽어 규칙에 거부됨 → 새 테마는 읽지 않고 생성
- 존재하지 않는 리비전 조회가 거부되어 정리 확인 불가 → 리비전 `get`은 부모 테마 소유자 기준
- 실패한 저장의 업로드를 즉시 지우면 직전 리비전·동시 저장과 공유하는 해시 파일을 지울 수 있음 → 즉시 삭제 대신 유예 후 정리
- 계정 다이얼로그 로그아웃이 에디터를 닫기만 해 빈 로딩 화면에 머묾 → 새 테마로 이동
- Firebase 전체가 하나의 지연 청크(gzip 186kB)로 묶여 에디터 시작이 늦어짐 → 인증/데이터 청크 분리

새로 다루는 위험:

- **회원 탈퇴**: 공개 share·테마·리비전·`users/{uid}/` 파일·`users/{uid}` 문서·Auth 계정 삭제, 공개 사본 파일은 함수가 정리. 다른 계정 데이터는 남음. 비로그인 호출 거부. 10분 이내 로그인 조건은 단위 테스트(`account.test.ts`). 연결 사본을 로컬 전용으로 바꾸면 이전 메모리 사본이 덮어쓰지 못함(`conflict`). E2E: 탈퇴 후 로그아웃 상태, 내 작업에 사본 유지, 공유 링크는 "이 테마를 볼 수 없어요."
- **복제**: 허용 값이 테마에 저장되고 share에 반영되며 저장·재공개 후에도 유지. 다른 계정은 바꿀 수 없음. `origin`이 저장·공개를 거쳐 유지. 규칙이 잘못된 `allowRemix`·`origin`을 거부. E2E: 허용 전에는 버튼 없음(다운로드는 가능) → 허용 → 비로그인 방문자가 복제 → 에디터·내 작업에 생성 → 그 사람이 가입해 공개 → 세 번째 방문자에게 "원본 … · by 원작자"와 원본 링크.
- **다운로드 남용 방지**: 한 IP에서 서로 다른 계정 3개는 집계되고 4번째는 집계되지 않음. 다른 IP는 집계됨. 한 IP에서 60회 호출하면 새 테마도 집계되지 않음(`X-Forwarded-For`로 IP 분리). 기존 인기순·중복 제외 테스트도 통과.
- **입력창 메뉴 버튼**: 생성 CSS의 메뉴 버튼 배경이 입력창 배경과 기타 버튼 색에서 파생되고 글자 대비가 4.5:1 이상. 참고 목록 검사(reference inventory guard) 통과.
