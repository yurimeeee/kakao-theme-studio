- [x] 요소별 기본값으로 되돌리기 (2026-10-17): 각 속성 패널 아래 버튼, 이미 기본값이면 비활성, 실행 취소 한 단계로 기록
- [x] 말풍선 모양 복사 (2026-10-17): "받는/보내는 말풍선에도 적용" — 모양·둥글기·텍스트 여백만 복사, 색상·이미지는 각자 유지(이미지 말풍선은 꼬리 방향이 반대인 경우가 많음)
- [x] 이미지 위치 조절 (2026-10-17): 목록·대화방·암호 배경과 기본 프로필 — 끌기/방향키로 보일 부분, 확대 100~300%, 가운데로. 설정 `focus {x,y,zoom}`(기존 설정은 가운데), 미리보기·내보내기·테마 아이콘(대화방 배경)·썸네일이 같은 계산. 미리보기 배경 기본 정렬이 '가운데 위'에서 내보내기와 같은 '가운데'로 바뀜
